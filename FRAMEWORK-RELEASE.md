MimiPip framework release, 1 November 2026. Based on public version 29, source 7378785e8ec41ea2d5fa6135bd126ec086cef69c. Restore that saved version to roll back. Serving target is the compiled Zyvorah-derived Next/React application via Vinext and Sites Worker: dist/server/index.js plus dist/client assets. The .openai manifest has no static directory, D1, R2, or service bindings. Legacy static outputs are rollback references, not the deployment target.

The reviewed 130-record snapshot is preserved in src/brand/review/reviewed-130.json. The served catalogue reconciles version 29 (149 designs, including 21 Polka Dots additions; the two retired floor designs are excluded). Legacy product and collection routes redirect into the actual React application. Read-only storefront: no charging, live account, chat, email or OS access. Non-read methods and non-browsing API routes are denied at the Worker. Payments are unavailable in both markets.

Build with the Sites build-site helper; run the built version with wrangler dev --local using dist/server/wrangler.json. Tested real Worker pages and mobile hydration, catalogue, search, product routes and disabled ordering. Existing source capabilities are retained; this release does not verify connected service parity.
